Full Stack Open — Part 12
Exercise 12: Persisting data in Redis

1. Tested Redis without a persistent volume.

2. Checked the Redis counter:
   GET added_todos
   Result: 1

3. Removed the Redis volume configuration from docker-compose.dev.yml.

4. Stopped and recreated the Docker containers:
   docker compose -f docker-compose.dev.yml down
   docker compose -f docker-compose.dev.yml up -d

5. Checked the counter again.
   Result: The key was missing (nil), confirming that data was not persisted.

6. Restored Redis volume configuration:

   redis:
     image: redis:latest
     command: redis-server --appendonly yes
     ports:
       - "6379:6379"
     volumes:
       - redis-data:/data

   volumes:
     redis-data:

7. Set a test counter:
   SET added_todos 9001
   Result: OK

8. Stopped and recreated the containers without deleting the volume.

9. Checked the counter:
   GET added_todos
   Result: 9001

Conclusion:
Redis data successfully survived Docker container recreation using the named volume redis-data.
