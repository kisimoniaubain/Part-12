Full Stack Open - Part 12
Exercise 8: Mongo CLI

Step 1: Start MongoDB

Command:
docker compose -f .\todo-app\todo-backend\docker-compose.dev.yml up -d mongo

Output:
Container todo-backend-mongo-1 Running

Step 2: Confirm MongoDB is running

Command:
docker ps

Output:
Container: todo-backend-mongo-1
Image: mongo:8
Status: Up
Port: 27017

Step 3: Open MongoDB CLI

Command:
docker exec -it todo-backend-mongo-1 mongosh -u the_username -p the_password --authenticationDatabase the_database

Output:
Connected successfully to MongoDB 8.3.13.

Step 4: Inspect the database

Commands:
show dbs
use the_database
show collections
db.todos.find({})

Output:
Database: the_database
Collection: todos

Existing todos were displayed successfully.

Step 5: Insert a new todo using Mongo CLI

Command:
db.todos.insertOne({
  text: "Increase the number of tools in my tool belt",
  done: false
})

Output:
{
  acknowledged: true,
  insertedId: ObjectId('6aeaef79fe930ffca8df608a')
}

Step 6: Verify the inserted todo in MongoDB

Command:
db.todos.find({
  text: "Increase the number of tools in my tool belt"
})

Output:
{
  _id: ObjectId('6aeaef79fe930ffca8df608a'),
  text: 'Increase the number of tools in my tool belt',
  done: false
}

Step 7: Verify the todo in the Express application

Command:
Invoke-RestMethod http://localhost:3000/todos | Format-Table text, done

Output:
text                                         done
Exercise 7 completed successfully            True
Learn about containers                       False
Increase the number of tools in my tool belt False

Result:
Successfully inserted the required todo through MongoDB CLI and verified that it is also available through the Express application.
