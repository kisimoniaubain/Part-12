# Exercise 11 - Redis CLI

## 1. Open Redis CLI

```powershell
docker exec -it todo-backend-redis-1 redis-cli
```

## 2. Find Redis keys

```redis
KEYS *
```

Output:
```text
1) "added_todos"
```

## 3. Read the counter

```redis
GET added_todos
```

Output:
```text
"9002"
```

## 4. Set the counter to 9001

```redis
SET added_todos 9001
```

Output:
```text
OK
```

```redis
GET added_todos
```

Output:
```text
"9001"
```

## 5. Verify through the application

```powershell
Invoke-RestMethod http://localhost:3000/statistics
```

Output:
```text
added_todos
-----------
9001
```

## 6. Create a todo using Postman

Method: POST

URL: http://localhost:3000/todos

Body (raw JSON):
```json
{
  "text": "Exercise 11 Redis CLI test"
}
```

The todo was successfully created.

Redis counter after creation:
```redis
GET added_todos
```

Output:
```text
"9002"
```

## 7. Delete the Redis key

```redis
DEL added_todos
```

Output:
```text
(integer) 1
```

Verify deletion:
```redis
GET added_todos
```

Output:
```text
(nil)
```

## 8. Verify counter after deleting the key

Created another todo using Postman:

```json
{
  "text": "Exercise 11 after deleting Redis key"
}
```

Then checked Redis:

```redis
GET added_todos
```

Output:
```text
"1"
```

## Result

Successfully accessed Redis using redis-cli, inspected keys, read and updated the counter, deleted the key, and verified that the counter starts again when a new todo is created.
