# Full Stack Open – Part 12

## Exercise 22: My Containerized Development Environment

This exercise uses DevEnv22, a full-stack application built with React, Node.js, MongoDB, Docker Compose, and Nginx.

## Exercise 23: My Containerized Production Environment

This exercise extends DevEnv22 with a production-ready Docker setup using:
- Multi-stage Docker build for the React frontend.
- Production Node.js backend.
- MongoDB with persistent storage.
- Nginx as a reverse proxy.
- Docker Compose to manage the production services.

The development environment runs on port 8081, while the production environment runs on port 8082.

**Public application repository:**  
https://github.com/kisimoniaubain/DevEnv22
